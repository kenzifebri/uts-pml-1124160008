# Soal 2 — Aplikasi Profil Mahasiswa

Aplikasi Flutter Android untuk Soal 2 UTS Aplikasi Mobile. Data profil disimpan
di memori dan mencakup halaman Login, Profil, Edit Profil, serta Tentang Saya.

## Menjalankan

```bash
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```

## Rilis APK

APK versi **v1.0.0** dapat diunduh dari GitHub Releases:

<https://github.com/kenzifebri/uts-pml-1124160008/releases/download/v1.0.0/app-release.apk>

## Pemeriksaan

```bash
flutter analyze
```
