# Soal 1 — Live Coding Halaman Profil Mahasiswa

Proyek Flutter untuk Soal 1 UTS Aplikasi Mobile. Seluruh widget pada
`lib/main.dart` merupakan `StatelessWidget`, sesuai ketentuan live coding.

## Menjalankan

```bash
flutter pub get
flutter run
```

## Pemeriksaan

```bash
flutter analyze
flutter test
```
